b# 🎬 Movie Review Sentiment Analysis

A Machine Learning-based web application that classifies movie reviews as **Positive** or **Negative** using Natural Language Processing (NLP) techniques.

---

## 🧠 Technologies Used

### 🔹 Machine Learning
- **Logistic Regression** – Used for binary classification of sentiments  
- **TF-IDF Vectorization** – Converts text data into numerical form for model training  

### 🔹 Programming Language
- **Python**

### 🔹 Libraries & Tools
- **pandas** – Data handling and preprocessing  
- **numpy** – Numerical computations  
- **scikit-learn** – Model training and evaluation  
- **nltk** – Text preprocessing (tokenization, stopword removal, stemming)  
- **joblib** – Model and vectorizer serialization  

### 🔹 Frontend / UI
- **Streamlit** – For building interactive web interface  

---

## 📊 Dataset

- Movie Reviews Dataset containing:
  - Review Text  
  - Sentiment Labels (Positive / Negative)

---

## ⚙️ Working Overview

- User provides a movie review as input  
- Text is preprocessed using NLP techniques  
- TF-IDF converts text into feature vectors  
- Logistic Regression model predicts sentiment  
- Output is displayed as **Positive** or **Negative** with confidence score  

---

## 🎯 Key Highlights

- Implemented end-to-end ML pipeline from preprocessing to deployment  
- Supports both single review prediction and bulk CSV analysis  
- Displays prediction confidence using probability scores  
- Designed with a simple and interactive UI
